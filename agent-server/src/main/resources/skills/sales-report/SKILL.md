# 销售报告技能

## 适用场景

- 查询指定时间范围的销售数据（分产品/合计）
- 生成销售周报、月报或临时报表文件

## 执行步骤（建议顺序）

1. **确认时间范围**：明确日期或“本月”“上周”按系统提供的当前日期换算，结束日期使用不含当天边界；完全未给时间范围时再询问。
2. **调用 `sales_query`**：传入 `startDate` 与 `endDate`（格式 YYYY-MM-DD，endDate 不含当天）。
   - 演示环境仅覆盖最近 90 天数据；超出范围会返回错误，此时告知用户可选范围。
3. **（如需文件）调用 `report_generate`**：传入标题、格式与统计区间。
   - 工具返回产物对象 ID 与下载路径，必须在最终答案中原样呈现给用户。
4. **输出最终答案**，结构要求：
   - **关键结论**：合计销售额、同比/环比（如可得）、TOP 产品；
   - **分产品明细**：产品名 + 金额 + 天数；
   - **口径说明**：统计周期（起止日期、endDate 不含当天）、币种 CNY、含税口径；
   - **产物说明**（如生成了文件）：文件名、对象 ID、下载链接。

## 数据口径

- 币种：人民币（CNY）
- 口径：自然日含税销售额
- 时间边界：`startDate` 含当天，`endDate` 不含当天
- 数据来源：销售数据库（工具返回的 `source` 字段为准）

## 校验清单（提交前自查）

- [ ] 答案中的数字与 `sales_query` 返回值完全一致（不得二次计算或四舍五入改变精度）
- [ ] 时间范围在答案中明确写出
- [ ] 生成了文件时，对象 ID 与下载路径完整呈现
- [ ] 未编造工具未返回的指标（如无同比数据则不写同比）

## 边界处理

- 用户只说"查一下"但没给时间范围 → 提问澄清，不假设
- 查询范围超出数据覆盖 → 告知覆盖范围，建议缩小范围
- 报告生成失败 → 告知失败原因，提供文字版数据作为降级方案
